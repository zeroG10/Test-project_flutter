# Recon A1 — Android, усі екрани (крок 2 Android-етапу)

**Дата:** 2026-09-29 · **Команда власника:** «якщо крок 0 і крок 1 виконані, то пуш і виконуй крок 2» ·
**Конфігурація:** емулятор `Pixel_7_API_36` — Pixel 7 · Android 16 (API 36, Google APIs arm64, 4 ГБ) ·
Appium 3.4.2 + UiAutomator2 7.5.2 · білд `[DEV] CT Mobile` 1.1.1 (178) **debug**, `CLIENT_BUILD=true`
(`automation/mobile/builds/android/BUILD_INFO.txt`).
**Скрипти:** `automation/mobile/scripts/recon/recon_android.py` (під'єднання до відкритої апки, дії, дампи, заміри часу;
одна довга сесія Appium) і `compare_android.py` (звірка текстів iOS-карт з Android-дампами). **Дерева:**
`qa/shared/recon-dumps/android-2026-09-29/*.xml` — 82 дампи; дані акаунта замазано `redact_dumps.py` (email, телефон,
ім'я; 0 залишків, 0 токенів). Знімки екрана — лише локально.

**Запити на сервер (усе прибрано):** 3 файли `POST /file/upload` + 5 джоб `POST /job` (`QA-AUTO-RA-0929-1145-*`) →
видалено (файли, потім джоби; на техніку 0 `QA-AUTO` джоб). Через UI на тестовій джобі CHECKIN: check-in → опитування →
фото → нотатка → здача (`POST /job/{id}/submit` → 500, джоба `submitted`, COPS — очікувано) → check-out (`completed`).
2 × `POST /job/assign/{phone}` на вигадані вільні номери 555-01xx (посилання згасають самі за 72 год). 1 вхід тестовим
акаунтом (DEV OTP), жодного неправильного коду. Ім'я акаунта **не змінювалось** (редагування — «Leave»), акаунт не
видалявся (діалог — лише Cancel). Побічний ефект: 5 сповіщень «… was assigned to you».

**Стан пристрою після розвідки:** апка залогінена, на Jobs list; дозволи сповіщень і геолокації — надано; у галереї 2
тестові фото; Chrome і Google Maps пройшли стартові майстри; «Location Accuracy» увімкнено; стилус Gboard вимкнено;
`adb root` вимкнено, дозвіл mock-локації для Appium Settings — стандартний.

## Покриття

`compare_android.py` по 284 iOS-локаторах: **165 — той самий текст на Android, 36 — частина тексту, 66 — структурні
(вирішуються на кроці 3), 17 не знайдено**: системні екрани iOS (Settings, алерт геолокації, PHPicker, ознака
завантаження SFSafari) — 8; інший текст на Android («Location disabled» → «Location access required») — 3; «No
notifications yet» (у техніка вже були сповіщення) — 1; не пройдено — 5 (див. нижче).

Пройдено: сплеш, Welcome, Login, код, реєстрація, SMS Terms, Privacy / Terms (Custom Tabs), дозвіл сповіщень, список і
календар, вкладки, деталі джоби (New / In progress / Submitted), вкладення (документи, фото, PDF, перегляд фото), карта,
телефон PF, check-in повністю (дозвіл, відмова, «Location Accuracy», ручне введення, не на об'єкті, підробка,
підтвердження), check-out, опитування (коротке, MO3: варіанти, дата, час), фотозвіт (вибір, редактор, розмітка, опис,
сітка, редагування, видалення, незбережені зміни), нотатки (усе), здача (незаповнене опитування, «Server error» +
Retry), сповіщення (рядки, банер, «Go to Settings» → налаштування Android), профіль (меню теми, вихід — Cancel,
редагування, незбережені зміни, видалення акаунта — Cancel), посилання («Link expired», «інший номер»).

**Не пройдено** (інших опитувань не створював / стани не виникали): «Repeat section», діалог видалення секції, «This field
is required», перехідні «Checking in» і «Successful» (на DEV здача завжди 500). Перевіряться на прогоні модулів (крок 4).

## Що так само, як на iOS

- Тексти екранів (див. «Покриття»); переноси рядків `\n` ті самі (заголовок Welcome, картка джоби, таймер, вкладки).
- Логін без повідомлення про формат (D-12); код: приховане поле 1×1, **«Incorrect code.» у дереві до вводу**,
  підтвердження після 4-ї цифри.
- Реєстрація: вибір SMS сам відкриває SMS Terms (D-9); галочка згоди неактивна до вибору SMS.
- **BUG-ORDL-001 відтворюється** (календар не оновлюється разом зі списком).
- Кнопки без підписів: перемикач список / календар, «download» / «close» у PDF, значок видалення фото, «Edit» у профілі
  (TD-JOBS-001, TD-ORDD-001, TD-PHR-001).
- Check-in / check-out, «не на об'єкті», здача (незаповнене опитування, 500 → «Server error» + Retry, на сервері —
  `submitted`), check-out → `completed`.
- Нотатки, фотозвіт, діалоги «Unsaved Changes» / видалення, профіль, тема, вихід, видалення акаунта — ті самі тексти.

## Середовище й інструменти (для кроку 3)

- **Зависання (ANR) — висновок Fable 5.1 (субагент, лише читання; стеки з `/data/anr`, журнал, властивості):** три ANR
  (11:47, 12:05, 12:16) — **нестача процесора в емуляторі через перевантажений Mac**, підсилена debug-збіркою (Dart JIT
  працює в основному потоці, CheckJNI). Взаємних блокувань і дефекту апки не знайдено: основний потік щоразу виконується
  або чекає в черзі на процесор; «зависання в `CheckJNI::NewRef`» — артефакт самого зняття стеків. Mac у ці хвилини:
  load 15–35 (Spotlight індексує нові файли Gradle / SDK / NDK, аналіз медіа, панель «Сховище», XProtect), вільної
  пам'яті ~110 МБ. Для харнесу: ANR на цьому емуляторі — **Blocked** (середовище), не Failed; «Wait» у циклі не тиснути.
- **Порожнє дерево** (11:47) — та сама причина: заблокований основний потік не відповідає на запит дерева.
  Окремо: на початку **нової** сесії Appium на статичному екрані дерево порожнє до першої зміни на екрані — у харнесі
  сесія одна на прогін і стартує із запуском апки; у розвідці — одна довга сесія.
- **Клавіатура:** `driver.hide_keyboard()` шле клавішу через Gboard (ESC / BACK) — саме на ній стався третій ANR; на Android
  не ховати клавіатуру клавішею (тап у нейтральне місце). Злиті поля Flutter (опитування) — вводити `mobile: type`.
  Gboard: навчальне вікно стилуса перекрило екран — вимкнено `settings put secure stylus_handwriting_enabled 0`.
- Chrome на свіжому AVD: майстер → «Use without an account»; Google Maps: «Make it your map» → Skip (один раз).
- Геолокація: `adb emu geo fix` — одноразова точка; під час check-in подавати кілька разів поспіль, інакше апка
  показує ручне введення. `set_location` Appium на емуляторі — теж `geo fix`, не mock. Справжній mock: `appops set
  io.appium.settings android:mock_location allow` + служба `io.appium.settings/.LocationService`, потім назад.
- Пошук за підказкою поля (`hint`) UiSelector не вміє — для полів дати / часу на кроці 3 потрібен інший спосіб.
- Тестові фото: `site_photo.jpg`, `site_photo_2.jpg` → `/sdcard/Pictures/` + сканування медіа.
- Рекомендації до прогонів (крок 4): перед повним прогоном — навантаження Mac < кількості ядер; закрити Системні
  параметри → Сховище, важкі застосунки; за бажанням власника — виключити `~/.gradle` і `~/Library/Android` з
  індексування Spotlight. Збірка profile / release — лише від команди розробки (ключ замовника); лишаємо debug.
