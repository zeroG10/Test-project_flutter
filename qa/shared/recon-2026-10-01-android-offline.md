# Recon A2 — Android без мережі (крок 5 Android-етапу)

**Дата:** 2026-10-01 · **Команда власника:** «виконуй крок 5» ·
**Конфігурація:** емулятор `Pixel_7_API_36` — Pixel 7 · Android 16 (API 36), тепер запускається з
`-dns-server 8.8.8.8,1.1.1.1` (не залежить від роутера Mac) · Appium 3.4.2 + UiAutomator2 · білд `[DEV] CT Mobile`
1.1.1 (178) debug, `CLIENT_BUILD=true`.
**Як:** `automation/mobile/scripts/recon/recon_android.py` (нові дії `email` / `otp`), мережа — `svc wifi` + `svc data`
на емуляторі; журнал апки — `scripts/recon/app_logs.py --android` (Dart VM service, лише локально — містить токен).
**Дерева:** `qa/shared/recon-dumps/android-2026-10-01-offline/*.xml` (дані акаунта замазано `redact_dumps.py`).
Знімки — лише локально. **Код апки** (`~/Projects/concert-app`, лише читання) — субагент Sonnet 5 зібрав карту офлайн-
поведінки; нижче лише те, що підтверджено на емуляторі, а код — як пояснення.

**Запити на сервер (усе прибрано):** 3 файли + 5 джоб `QA-AUTO-RA-1001-1430-*` → видалено (на техніку 0 `QA-AUTO`).
Через UI на джобі PROG: опитування (офлайн), 2 нотатки й 1 фото (офлайн), видалення нотатки й фото (офлайн). Вхід
тестовим акаунтом — 1 раз (DEV OTP), невдалих перевірок коду — 1 («No internet connection», офлайн). Здачі не було.
