## Моделювання SMS із посиланням (Q-ORDL-A1, 2026-09-29)

Перевірено на емуляторі: `adb emu sms send <номер> "… <посилання>"` — SMS приходить у Google Messages (перший запуск
Messages — «Use Messages without an account»); апці дозволено відкривати посилання домену DEV так, як це вмикає
користувач («Open supported links»): `pm set-app-links-user-selection --user 0 --package <пакет> true
copsfieldservices.dev.concerttech.com`; тап по посиланню в SMS → **відкривається апка** → діалог (невалідний ключ →
«Link expired», 17 с разом зі стартом апки). Налаштування після проби повернуто.

Що це моделює і чого ні: посилання — те саме, що сервер кладе в SMS (`POST /job/assign/{phone}`); доставку
оператором імітує емулятор; перевірку домену ↔ підпис (App Links) заміняє дозвіл користувача — для збірки замовника
вона працює на проді (власник). Шлях через email (канал email при реєстрації) — лише якщо буде доступ до скриньки;
зараз його немає. Тести посилань на Android (крок 5): SMS на емуляторі → тап у Messages → апка.
