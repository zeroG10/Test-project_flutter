1. Summary

Regression testing of the Concert Technologies Field Technicians iOS App finished on 28 September 2026 with no unexpected failures. Of the 645 checks in the QA checklist, 462 (72%) are automated: 449 passed, 6 are red because of 5 known, reported defects, and 7 could not run on the test environment for agreed reasons. 6 defects are open, none of them critical or major. The other 183 checks are not automated, each for a written reason (section 5).

2. Scope

Automated functional regression of the field technicians' mobile app (iOS) through its user interface, on the test environment (DEV). The checklist covers 12 modules:

  • Splash
  • Authentication
  • Order list
  • Order details
  • Check in out
  • Order progress
  • Submit deliverables
  • Survey
  • Photo report
  • Notes
  • Notifications
  • Profile

Out of scope

  • API testing as a discipline (the API was used only to prepare test data and to verify what the app stored)
  • Performance and load testing
  • Security testing
  • The web admin panel
  • The production environment
  • Real devices, tablets and operating-system versions other than those in section 3
